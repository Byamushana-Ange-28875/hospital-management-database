# Hospital Management Database System

## Project Overview

This project is an Oracle SQL database designed to manage the main operations of a hospital. It provides a structured way to store and manage information about patients, doctors, appointments, prescriptions, billing, and other hospital-related activities.

The project demonstrates the use of relational database concepts and PL/SQL programming to create a functional hospital management system.

## Project Type

This was a **group project** completed as part of my Software Engineering studies. The project involved collaborating with other students to design and develop a hospital management database using Oracle SQL and PL/SQL.

## Technologies Used

* Oracle Database XE

## Database Features

The database includes the following main components:

* Patient management
* Doctor management
* Medical appointments
* Prescriptions
* Prescription refills
* Billing
* Medical specializations
* Appointment history
* Doctor performance reporting
* SMS reminder simulation

## Main Database Tables

The database contains the following main tables:

| Table                  | Purpose                                 |
| ---------------------- | --------------------------------------- |
| `patients`             | Stores patient information              |
| `doctors`              | Stores doctor information               |
| `appointments`         | Manages patient appointments            |
| `prescriptions`        | Stores prescriptions issued to patients |
| `billing`              | Manages hospital billing information    |
| `specializations`      | Stores medical specializations          |
| `appointment_history`  | Keeps records of appointment changes    |
| `prescription_refills` | Manages prescription refill information |

## How to Run the Project

### Requirements

To run this project, you need:

1. Oracle Database XE
2. Oracle SQL Developer
3. A connection to an Oracle XE database

### Installation

1. Clone or download this repository.
2. Open `HOSPITAL_DATABASE.sql` using Oracle SQL Developer.
3. Connect to your Oracle XE database.
4. Run the SQL script.
5. Check the database objects created in Oracle SQL Developer.

### Database Objects

After running the script, the database should contain the required tables, sequences, procedures, functions, triggers, and packages used by the hospital management system.
